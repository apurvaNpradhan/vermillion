# body

Public surface: `index.ts`. `body-state.tsx` is the shared loading and empty state. Each folder is one feature.

- `weight/`: the weight screen, trend card, weigh-in grid, logging sheet and height row. Start at `weight-screen.tsx`.
- `measurements/`: check-ins, tracked metrics and the metric screens. Start at `measurements-screen.tsx`.
- `photos/`: progress photos, comparison and hiding. Start at `photos-screen.tsx`.
- `reminders/`: weigh-in and check-in reminder scheduling and settings rows. Start at `reminder-schedule.ts`.

# Sounds

`rest_end.wav`: the "notification" cue of the "zen" pack from [uisfx](https://github.com/romainsimon/uisfx)
v0.4.0 (npm package `uisfx`, `sounds/zen/notification.mp3`), converted to 16-bit mono 44.1 kHz WAV
with ffmpeg (iOS notification sounds cannot be MP3; Android raw resources accept WAV). Audio is
CC0-1.0 (public domain); the uisfx code is MIT. The file name uses an underscore because Android
resource names cannot contain a hyphen.

# Palette inspiration credits

Vermillion's hand-tuned themes draw inspiration from these MIT-licensed projects:

- Chalk: [Flexoki](https://github.com/kepano/flexoki), Steph Ango.
- Frost: [Nord](https://github.com/nordtheme/nord), Arctic Ice Studio.
- Iron: [Gruvbox](https://github.com/morhetz/gruvbox), Pavel Pertsev.
- Dusk: [Rosé Pine](https://github.com/rose-pine/rose-pine), Rosé Pine contributors.

The initial implementation contains only copies of Vermillion Classic as placeholders.
When incorporating upstream palette values, retain the corresponding upstream MIT copyright
and permission notice alongside these credits.

# Native QA and repair pass, 11 November 2026

Device: Motorola edge 60 pro, connected over ADB. The Android development client was rebuilt and installed with `adb install -r`; existing account and training data were retained. Work remains uncommitted for review.

## Changes

| Area                | Finding and change                                                                                                                                                                                                                                                                                                                                                                   |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Workout preview     | Hermes lacks `Intl.RelativeTimeFormat`. Calendar-day labels now use translated resources; regression tests reproduce the missing constructor and cover DST and future dates. The preview opens on the device and shows “Last done yesterday.”                                                                                                                                        |
| Plurals             | A device probe confirmed missing `Intl.PluralRules`. English FormatJS rules load before i18next. A regression test removes the native constructor and checks singular, plural and zero labels.                                                                                                                                                                                       |
| Home                | The chart query reads nine weeks instead of lifetime history. Recent sessions use a separate three-session query. Loading shows a skeleton. Stat values no longer repeat their labels.                                                                                                                                                                                               |
| History             | Home links anchor the History list below detail; detail has a History fallback. Exercise names now come with the history query, replacing one live detail query per card. Log past workout uses a quieter header action.                                                                                                                                                             |
| Session detail      | Exercise titles open exercise detail. Set accessibility labels describe the set instead of advertising an unavailable type-changing action.                                                                                                                                                                                                                                          |
| Active session      | The menu offers Muscles and Discard workout. Discard states the completed-set count, asks for confirmation, uses the existing soft delete and Undo, and exits only after success. Read-only and finished sessions cannot use this action.                                                                                                                                            |
| Finish summary      | An unfinished workout can return to logging or be discarded. Android Back returns to logging before saving and exits the later finished steps.                                                                                                                                                                                                                                       |
| Previous            | Loaded histories are retained within the current account's write scope when an exercise is added. Existing exercises remain tickable; new exercises wait for their own history. Loading uses a skeleton, and failed history has a Retry action.                                                                                                                                      |
| Completed sets      | The whole row uses a neutral surface fill; value cells are transparent, and the tick retains the selected fill. This follows Classic theme tokens.                                                                                                                                                                                                                                   |
| Calculator          | Inventory watches and solving are enabled only while open. The opening weight is captured, target updates are deferred, and calculation keys use meaningful inputs. The selected bar determines plate units and colours. The nearest valid load is selected, ties prefer lower, and the drawing and Use button follow the chosen option. Per-side text makes the drawing accessible. |
| Equipment           | Grouped by unit, with Back navigation inside the session stack. Custom equipment uses a visible keyboard-aware sheet. Default seeding waits for first sync and empty loaded inventory; missing kit additions preserve existing items. Switch thumbs are explicit and were observed in both positions on-device.                                                                      |
| Motion and feedback | Existing tick, record, rest and swipe haptics remain. Metric changes and expanding the muscle list use the shared selection haptic. No extra animation was added to the logging grid.                                                                                                                                                                                                |
| Reanimated          | A pinned pnpm patch makes bottom-sheet hook dependencies web-only, preserving their web fallback. No warning suppression was added.                                                                                                                                                                                                                                                  |
| Lists               | All LegendList instances explicitly keep `recycleItems={false}` to preserve existing row state behavior and remove the warning.                                                                                                                                                                                                                                                      |
| Notification icon   | The old generated native project lacked the drawable. The new APK contains `drawable/notification_icon` and the notification metadata. Removed the forced near-black notification tint.                                                                                                                                                                                              |

The calculator device check also exposed a portal-context crash: data hooks rendered inside the sheet portal could not access QueryClient. The hooks now resolve outside the portal, while only sheet UI is portalled. The final calculator was opened after a cold reload on the Motorola, showing the 20 kg target, bare-bar drawing, exact total, available plates and one Use action without a QueryClient error. The sheet container remains mounted while closed; inventory watches and solving are explicitly gated.

Opus reviewed the feature flows and planned these changes. Sonnet implemented the calculator and equipment work. The parent integrated and checked the changes, including the portal fix.

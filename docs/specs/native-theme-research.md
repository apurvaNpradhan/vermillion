# Native theme research

Slate blue is the strongest first mockup for Cinnabar. Rainy asphalt, the jellyfish's muted blue-grey ramp and the pearl/navy reference all translate into quiet surfaces with clear lightness steps. Olive gives the app a warmer identity but needs more separation between the current set and a logged set. Mulberry gives the strongest visual departure from Graphite & chalk and needs the most care around warnings and destructive actions. These are design judgments to test on the same live workout screen. [Cinnabar design system](../../DESIGN.md)

| Direction  | Where the references fit                                                                                                                                                                                                                          | What to check mid-workout                                                                                                                                                                                                                |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Slate blue | Use asphalt and pearl for the dark and light canvases, with a blue-grey ramp for cards and controls. Use navy or pale slate for current-state cues. The pixelated botanicals suggest an optional chart color, and sea green can carry completion. | A muted blue can disappear into a blue-grey card or resemble warmup and protein blue. Make the current row identifiable by its placement and an explicit cue, and verify the slate foreground on its actual fill.                        |
| Olive      | Use lightly tinted stone and charcoal for large areas. Use forest or a lighter olive for current-state cues.                                                                                                                                      | A forest selection beside a green check can make both rows look completed. Keep the main action neutral and give the current row a distinct lightness and shape. Verify it beside the success check in both modes.                       |
| Mulberry   | Pair parchment in light mode with a low-chroma plum-charcoal in dark mode. Use burgundy or pale mulberry for small current-state cues.                                                                                                            | Burgundy can read as an error or compete with the existing red failure set mark. Give danger a visibly different tone, an icon and explicit wording. Check that the current row and an error still read correctly when visible together. |

## Roles and readability

- Start with the Graphite & chalk hierarchy. Keep one high-contrast filled action, large tabular weight and rep values, and primary ink for the rest countdown. Treat the accent as “you / now.” Give the current row a label or distinct marker, logged rows a checkmark, and the timer a visible “Rest” label. Apple's own Workout app offers a comparable pattern in Up Next, which shows what remains in the current interval alongside what comes next. [Cinnabar design system](../../DESIGN.md) · [Apple HIG on color](https://developer.apple.com/design/human-interface-guidelines/color) · [Apple Watch Custom Workouts](https://support.apple.com/en-gb/guide/watch/apd66fcd5c5c/26/watchos/26)
- Assign tones by role before picking swatches. Radix uses steps 1–2 for backgrounds, 3–5 for component fills and states, 6–8 for borders, 9–10 for solid fills and 11–12 for text. Its text-step guarantees use APCA on step 2 of the same scale. Measure the actual Cinnabar foreground and background pairs with WCAG ratios. Linear's theme generator is a precedent for adjusting base, accent and contrast independently. [Radix scale](https://www.radix-ui.com/colors/docs/palette-composition/understanding-the-scale) · [Linear theme design](https://linear.app/now/how-we-redesigned-the-linear-ui)
- Use WCAG 2.2 as a measurement reference. AA calls for 4.5:1 for ordinary text and 3:1 for qualifying large text. Required control and state indicators and meaningful graphic marks need 3:1 against adjacent colors. Cinnabar already tests primary text at 7:1 on the canvas and cards. Use the same target for the timer on its floating bar. Check labels on filled and pressed buttons, the current-row marker on its tint, and the checkmark on the done fill. [WCAG 2.2 use of color](https://www.w3.org/TR/WCAG22/#use-of-color) · [Text contrast](https://www.w3.org/TR/WCAG22/#contrast-minimum) · [Non-text contrast](https://www.w3.org/TR/WCAG22/#non-text-contrast) · [Cinnabar theme rules](../../packages/ui/src/tokens/theme-rules.test.ts)
- Compare the same live workout with a current set, a completed set, an upcoming set and a running rest timer. In a quick glance, check which set to log, what was already logged, how long is left and where to tap. Repeat in grayscale and on a phone in bright and dim light, with standard and increased contrast in both appearances. [Apple HIG on color](https://developer.apple.com/design/human-interface-guidelines/color)
